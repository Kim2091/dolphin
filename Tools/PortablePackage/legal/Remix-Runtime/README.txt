Licenses for the RTX Remix runtime shipped alongside Dolphin
============================================================

Dolphin's own licensing is covered by COPYING and Licenses\ at the root of this
package. The files in THIS folder cover the Remix runtime and everything it
bundles -- which is most of the disk space in this download.

  LICENSE-dxvk.txt        DXVK, on which the Remix runtime is built.
  LICENSE-MIT.txt         The MIT-licensed portions of the same.
  ThirdPartyLicenses.txt  Every third-party component the runtime links or
                          ships: NVIDIA DLSS / NRD / NRC / RTXIO / Aftermath,
                          Intel XeSS, AMD FidelityFX, OpenUSD, Boost, TBB,
                          Python, and the rest.

These are reproduced verbatim from the runtime's source repository. Nothing in
this package modifies them, and nothing here grants rights beyond what they say.

The runtime binaries are built from a fork of dxvk-remix; the exact repository,
branch and commit are recorded in VERSION.txt at the root of this package.
