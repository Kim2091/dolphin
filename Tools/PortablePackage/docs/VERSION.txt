This is a fork with its own ABI line. A stock RTX Remix release substituted for
the runtime will fail at load with INCOMPATIBLE_VERSION. The ABI number alone
does not identify a build — different forks have shipped the same 0.1000.0 from
different lineages. The "Identifies" string above is read out of the shipped DLL
and is the reliable marker; you can confirm it yourself with:

    grep -aoE "remix-[a-zA-Z0-9._/-]*\+[0-9a-f]{7,}" {{RUNTIME_DLL_NAME}}

If you are reporting a bug, quote the Version and Commit above — the DLL/EXE
file date is not a reliable way to tell builds apart.
